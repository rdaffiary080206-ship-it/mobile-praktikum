# Proyek Pemrograman Mobile

## Deskripsi

Aplikasi latihan untuk praktikum pemrograman mobile.

## Pengembang

Nama panggilan / akun GitHub: rdaffiary080206-ship-it

## Status

Proyek awal perkuliahan.

## Tujuan

Mengatasi social media fatigue dan menumbuhkan interaksi sosial yang otentik tanpa rekayasa visual berlebih.

## Rencana Fitur

1. Kamera Ganda (Dual-Camera Capture) secara spontan.
2. Jendela waktu unggah terbatas (2-Minute Time Window).
3. Gamifikasi kebiasaan harian dengan perlindungan Streak Freeze.

## Cara Menjalankan

Jalankan perintah berikut pada direktori proyek:

```bash
flutter pub get
flutter run
```
